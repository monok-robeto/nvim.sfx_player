1. INTRODUCTION                                     *nvim-sfx-player-introduction*

nvim.sfx_player opens a floating popup that plays an audio file (mp3, wav,
flac, ogg, …) and shows a live, colored timeline you drive from the keyboard.
Playback is handled by |mpv| through its JSON IPC socket, so play/pause, seek
and volume are real-time — no process restarts.

==============================================================================
2. REQUIREMENTS                                     *nvim-sfx-player-requirements*

    - Neovim >= 0.9
    - mpv         (required)   https://mpv.io
    - ffprobe     (optional)   https://ffmpeg.org  -- extra metadata

macOS: >
    brew install mpv
    brew install ffmpeg
<
Linux: >
    sudo apt install mpv ffmpeg      " Debian/Ubuntu
    sudo dnf install mpv ffmpeg      " Fedora
    sudo pacman -S mpv ffmpeg        " Arch
<

4. NVIM-TREE INTEGRATION                                *nvim-sfx-player-nvimtree*

                                            *nvim.sfx_player.nvimtree_attach()*
nvimtree_attach({bufnr} [, {opts}])

Bind <CR>/<Tab> in nvim-tree so audio files open the player and everything
else keeps the default behaviour. Call it after default_on_attach(). >

    require("nvim-tree").setup({
      on_attach = function(bufnr)
        local api = require("nvim-tree.api")
        api.config.mappings.default_on_attach(bufnr)
        require("nvim.sfx_player").nvimtree_attach(bufnr)
      end,
    })
<
{opts} may set `open` and `preview` to use different keys: >

    require("nvim.sfx_player").nvimtree_attach(bufnr, { open = "o" })
<

7. CONTROLS                                             *nvim-sfx-player-controls*

Inside the popup (all keys configurable, see |nvim-sfx-player-config|):

    <Space>        play / pause
    <Right>        seek forward  (seek_step seconds)
    <Left>         seek backward (seek_step seconds)
    <Up>           volume up     (volume_step %)
    <Down>         volume down   (volume_step %)
    Shift+L (L)    cycle playback mode, press again for the next one
    Shift+> (>)    next track in the folder
    Shift+< (<)    previous track in the folder
    <Esc> / q      quit

The popup itself spells all of this out at the bottom (key + what it does),
so you don't have to come back here to remember a shortcut.

                                                *nvim-sfx-player-playlists*
Opening a file scans its folder for sibling audio files (sorted by name)
to build an album/playlist. When it finds more than one, the popup gains
an album line (icons.album + folder name) up top. `L` cycles through four
playback modes:

    single (default)   repeat the current file forever
    sequential          play the folder in order, stop after the last file
    shuffle              play the folder in random order, stop once every
                          file has played once
    repeat               play the folder in order, looping back to the
                          first file

`>` / `<` skip to the next/previous track manually in any mode (following
the shuffled order while in shuffle mode). Track changes reuse the running
mpv process (`loadfile ... replace`), so switching songs is gapless. Set
the starting mode with `mode_default`.

8. CONFIGURATION                                          *nvim-sfx-player-config*

Defaults: >

    require("nvim.sfx_player").setup({
      title = "nvim.sfx_player",
      mpv_path = "mpv",
      ffprobe_path = "ffprobe",

      default_volume = 100,        -- 0-130
      volume_step = 5,             -- % per press
      seek_step = 3,               -- seconds
      mode_default = "single",     -- single | sequential | shuffle | repeat

      update_interval = 200,       -- ms
      bar_width = 34,              -- cells
      border = "rounded",
      auto_close_on_leave = true,

      window = { width = nil, row = nil, col = nil },

      icons = {
        file = "🎵", album = "💿", paused = "▶", playing = "⏸", volume = "🔊",
        mode_single = "🔂", mode_sequential = "➡",
        mode_shuffle = "🔀", mode_repeat = "🔁",
      },

      extensions = {
        "mp3","wav","flac","ogg","oga","opus","m4a",
        "aac","wma","aiff","aif","alac","ape","mka",
      },

      keymaps = {
        play_pause    = "<Space>",
        seek_forward  = "<Right>",
        seek_backward = "<Left>",
        volume_up     = "<Up>",
        volume_down   = "<Down>",
        cycle_mode    = "L",
        next_track    = ">",
        prev_track    = "<",
        quit          = { "<Esc>", "q" },
      },

      highlights = { ... },        -- see below
    })
<
Each keymap value may be a string, a list of strings, or `false` to disable
that action. keymaps, highlights and icons are replaced per key, so partial
overrides never leave stale defaults behind.

9. HIGHLIGHTS                                          *nvim-sfx-player-highlights*

Every highlight value is passed to |nvim_set_hl()|. Use `{ link = "Group" }`
to follow the colorscheme or explicit attrs like `{ fg = "#7aa2f7" }`. They
are re-applied on every |ColorScheme| event. Groups and their config keys:

    SfxPlayerTitle          title
    SfxPlayerAlbum          album    (album line, only when >1 file was found)
    SfxPlayerName           name
    SfxPlayerMeta           meta
    SfxPlayerIcon           icon
    SfxPlayerBarFilled      filled   (played part of the bar)
    SfxPlayerBarKnob        knob     (playhead)
    SfxPlayerBarRemain      remain   (unplayed part of the bar)
    SfxPlayerTime           time
    SfxPlayerVolume         volume
    SfxPlayerMode           mode     (playback mode + playlist position)
    SfxPlayerHelp           help

Example: >

    require("nvim.sfx_player").setup({
      highlights = {
        filled = { fg = "#a6e3a1", bold = true },
        knob   = { fg = "#f9e2af" },
        remain = { fg = "#45475a" },
      },
    })
<
